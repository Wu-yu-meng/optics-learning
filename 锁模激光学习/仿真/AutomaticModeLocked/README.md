## 当前消融测试（保留可视化）

已对接test分支的三个观测窗口：腔内总功率及x/y分量、OC输出的虚拟示波器、腔内归一化光谱。
`VirtualOscilloscope`只观测OC输出，保留同一套功率、光谱和示波器窗口及播放/EPC控制。当前消融链路为EDF->EPC->OC->PD->固定拨片->SMF：保留已对齐参数、EDF带宽和噪声，以及PD与SMF之间的固定拨片；本轮只恢复SMF的自适应对称分步传播，不改变其他器件顺序或观测逻辑。

在项目根目录构建并运行（需要可用的桌面显示环境）：

```bash
cmake -S 锁模激光学习/仿真 -B 锁模激光学习/仿真/build
cmake --build 锁模激光学习/仿真/build --target AutomaticModeLocked -j 2
./锁模激光学习/仿真/build/AutomaticModeLocked/AutomaticModeLocked
```

- 启动时暂停；空格运行/暂停，D或右方向键只传播一圈，R恢复初始光场并重置EDF随机序列（不重置EPC滑块），Q或Esc退出。
- EPC滑块设置下一圈的相位，不修改已经算出的当前光场。
- A或AUTO按钮重新设置光功率和示波器的纵轴；其他帧保持量程不变，超出量程时提示CLIPPED。
- 默认帧延迟20 ms，`[`减速、`]`加速；实际帧时间还包含计算和绘图耗时。
- 光谱横轴是物理频偏f-f0；采用exp(i*(beta0*z-omega0*t))约定，所以与标准DFT坐标反号。
- 光谱仅在观测副本上做4倍补零插值，不提高真实频率分辨率，也不修改传播采样网格。
- 边缘能量警告只是有限窗口/FFT周期边界的风险提示，不等于FFT函数出错，也不能仅凭它认定结果已污染。
- 腔内功率和光谱的观测点是SMF出口；第1圈起，示波器缓存同一圈EDF、EPC之后的实际OC输出。第0圈只预览初始光场按OC分光比例得到的信号；暂停、AUTO和调滑块不会额外传播或生成噪声。

当前main使用16384点、5 fs采样，窗口为81.92 ps。保留SMF参数gamma=1.3e-2 W^-1*m^-1、长度5 m、beta2=-21.7 ps^2/km。SMF每段按半步色散->整步Kerr->半步色散传播，相邻半步色散合并。计算优化与test对齐：缓存半步/整步色散传递函数，仅在采样点数、采样间隔或分段数变化时重建；Kerr展开为等价的UV标量计算，复用偏振矩阵，DFT提供原地接口以减少临时Eigen矩阵和逐段光场重建（内部仍使用OpenCV工作矩阵，并非零复制）。这些优化不改变物理模型、器件顺序或分段规则；同一个SMF实例因有可变缓存，不应并发调用propagate()。按入口峰值功率估计步数，目标单步非线性相移0.05 rad、最多256段；这一入口估计和上限并非步长收敛证明。EDF保留g0=0.01 m^-1、饱和能量100 pJ、长度40 m，以及4 THz高斯增益系数谱；各频率的复振幅乘exp[g(f)*L/2]后逆变换回时域。PD后、SMF前保留主轴22.5°、相位延迟90°的独立固定拨片，复用EPC模型，但不受四个EPC滑块控制。

逐圈波形变化不等于数值出错，尚未稳定的腔内状态也可能明显变化。分步仅针对Kerr与色散联合传播的离散误差，不会自动消除有限时间窗口的边界风险；应通过缩小传播步长、扩大窗口等独立对照核查，不能仅凭相邻两帧确定原因。

EDF在增益之后、每次传播时加入带限复高斯噪声，采用test的固定能量归一化简化ASE等效模型，不是根据泵浦或噪声系数标定的完整ASE模型。main设置每圈噪声总能量为1e-6 pJ（两个偏振、整个时间窗口的总和），噪声功率谱带宽为4 THz，随机种子为20261018。噪声构建后归一化自身能量，再与光场复振幅相加；由于存在干涉项，输出总能量不一定恰好等于原场能量加上噪声能量。

EDF构造函数参数顺序为g0、饱和能量pJ、长度m、带宽THz、每次噪声能量pJ、随机种子；第四个参数仍为带宽，与test的参数顺序不同。带宽默认4.0，噪声能量默认0.0（关闭），种子默认20261018。propagate()会推进随机数状态，因此不再是const；reset_noise()恢复初始种子。暂停、AUTO、刷新和调滑块不调用EDF传播，不生成新噪声；按R会重置初始场和噪声序列，EPC设置保持不变。复现实验时还需保持相同的EPC调节过程和传播圈数。
