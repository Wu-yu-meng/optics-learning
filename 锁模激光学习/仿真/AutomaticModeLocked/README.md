移植顺序

| 顺序 | 内容 | 验证重点 |
|---|---|---|
| 1 | 接通逐圈传播 | 本圈输出成为下一圈输入，记录每圈能量和峰值 |
| 2 | `FourierTransform` | 正逆变换能恢复输入，频率轴和归一化正确 |
| 3 | SMF二阶色散与分步传播 | 分别检查纯色散、纯Kerr，再检查组合传播及步长收敛 |
| 4 | EDF有限增益带宽 | 保留现有饱和增益，检查不同频率的放大效果 |
| 5 | EDF噪声 | 噪声强度可配置，固定种子后能够重复运行 |
| 6 | 独立固定拨片 | 接入SMF前，检查偏振变化和功率守恒 |
| 7 | 探测器与可视化 | 依次加入光功率图、光谱图和示波器电压图 |
