该项目目前计划分为两个部分,一个是仿真部分，一个是实验部分。
当前在进行的是仿真部分，需要搭建的一个光纤光路的仿真和反馈算法的验证。

目前问题主要依然还是在如果进行仿真上。现在的想法是。为每个器件搭建一个仿真模块。比方说wdm，edf,pc,oc,smf,pd-iso这些器件。但是主要是不直到应该如何研究里面光传播的物理规律，不知道什么方式进行仿真，应该仿真光的哪些性质。

## 最简光场可视化

程序启动后会在可视化窗口中实时计算谐振腔内部的光场。运行命令为：

```bash
./build/AutomaticModeLocked/AutomaticModeLocked
```

第0圈表示初始光场，第n圈表示完成第n次
`OC -> EPC -> PD -> EDF -> 虚拟固定拨片 -> SMF` 传播后的谐振腔内部光场。

- 拖动四个 `EPC CHx phase (deg)` 滑块：设置相应拨片的相位差，在下一圈经过EPC时生效；
- 空格：连续运行或暂停；
- `D` 或右方向键：暂停并单步计算一圈；
- `[`：每帧增加50 ms等待时间，减慢播放；
- `]`：每帧减少50 ms等待时间，加快播放；默认等待时间为20 ms；
- `A`：按当前波形重新计算一次两个窗口的纵轴量程；
- `R`：保留当前EPC设置，将光场和圈数恢复到初始状态；
- `Q` 或 `Esc`：退出。

图中的 `Total`、`X`和 `Y` 分别是
`|Ax|^2 + |Ay|^2`、`|Ax|^2`和 `|Ay|^2`，单位为W。主光场图第一次显示时自动定标，此后保持纵轴不变；点击控制面板中的 `AUTO vertical scales` 或按 `A` 才会重新定标。量程下限为1 mW，防止已经熄灭的微弱ASE噪声被放大成满屏波形。总能量低于 `1e-4 pJ` 时，界面会明确显示 `NOISE FLOOR`。超出当前量程时显示 `CLIPPED`，但不会自行改变纵轴。左下角的 `Peak` 和 `Energy` 保留绝对数值，用于判断实际功率变化。

程序同时显示第二个 `Simulated oscilloscope` 窗口。它显示OC输出光场经过30 dB光衰减、0.9 A/W响应度、50 ohm负载和50 GHz一阶低通探测链路后的电压，单位为mV。示波器纵轴同样只在第一次显示时自动定标，之后保持固定；点击 `AUTO vertical scales` 或按 `A` 才会按当前波形重新定标。超出当前量程时界面显示 `CLIPPED`，但不会自行改变纵轴。该窗口目前仍显示81.92 ps局部快时间，不是完整腔往返周期的脉冲列。

第三个 `Optical spectrum` 窗口显示当前腔内两个偏振分量相加后的归一化功率谱。横轴是相对于中心载频的频率偏移，固定显示 `-4 THz` 到 `+4 THz`；纵轴是相对光谱峰值的功率，固定显示 `-60 dB` 到 `0 dB`。81.92 ps真实时间窗口对应约12.2 GHz的真实频率分辨率，显示时再进行4倍零填充，使曲线采样间隔约为3.05 GHz；零填充只用于平滑显示，不会增加真实频谱信息。窗口同时显示光谱峰值偏移和半高范围。由于它是归一化光谱，必须结合主窗口的绝对能量和 `NOISE FLOOR` 提示判断，不能把微弱ASE误认为有效激光光谱。

可视化会统计时间窗口左右各5%的能量。当外侧10%区域的能量占比超过 `1e-4`且总能量足够大时，界面会显示 `FFT boundary wrap risk`并自动暂停一次。警告表明局部窗口的周期回绕已可能影响结果，此时示波器窗口也会标记数据不可靠。

## 当前的数值模型

光场是两个偏振方向的复包络 `Ax(t)` 和 `Ay(t)`，采样值单位为 `sqrt(W)`。当前使用16384个采样点和5 fs采样间隔，对应81.92 ps时间窗口。100 fs脉冲的FWHM范围内有约20个采样点，同时进一步降低多脉冲接触FFT周期边界的风险。

EDF当前包含：

- `g0=0.01 m^-1`、`L=40 m`，未饱和功率增益为 `exp(g0*L)=1.49`；
- `Esat=100 pJ` 的脉冲能量饱和增益；
- 整个光场的增益系数谱为FWHM `4 THz` 的高斯分布，中心频率获得完整增益，远离中心的分量逐渐不再获得增益；
- 每次通过EDF后加入总能量 `1e-6 pJ` 的复高斯ASE噪声；
- ASE噪声使用相同的 `4 THz` 功率谱带宽，避免白噪声占满整个数百THz的数值带宽；
- 固定随机种子，按 `R` 重置后可重复同一次实验。

SMF当前包含：

- `gamma=1.3e-3 W^-1 m^-1` 的双偏振Kerr非线性；
- `beta2=-21.7 ps^2/km` 的二阶色散；
- `L=5 m`；
- 对称分步傅里叶法：半步色散、一步Kerr、半步色散；
- 按当前峰值功率自动选择分步数，目标单步非线性相移不超过0.05 rad，最多64步。

PD输出固定为45°线偏振。为了避免该线偏振在当前U/V Kerr模型中满足 `Pu=Pv`、只能获得共同非线性相位，程序在EDF和SMF之间加入一个固定虚拟拨片作为集总等效。它采用22.5°主轴和90°相位延迟，把进入SMF的光变成椭圆偏振，使两个圆偏振分量均非零且功率不相等。虚拟拨片不占用界面的四个EPC滑块。

当前时间窗口仍是围绕单个脉冲的局部快时间窗口，不是完整的几十或几百ns腔往返时间。它可用于研究单脉冲的展宽、压缩、分裂和稳定性，但暂时不能直接判断整个腔周期内的谐波锁模阶数。
