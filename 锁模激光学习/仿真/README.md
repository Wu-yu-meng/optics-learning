# 本目录用于存放仿真代码

## 默认单位
| 物理量 | 建议单位 | 变量名示例 |
|---|---:|---|
| 时间 \(t\) | fs（飞秒） | `time_fs` |
| 空间位置 \(z\) | μm（微米） | `position_um` |
| 普通频率 \(f\) | THz | `frequency_thz` |
| 角频率 \(\omega\) | rad/fs | `angular_frequency_rad_per_fs` |
| 波长 \(\lambda\) | μm 或 nm | `wavelength_um` |
| 波数 \(k\) | rad/μm | `wave_number_rad_per_um` |
| 相位 | rad | `phase_rad` |
| 光强 | 相对单位 | `intensity_au` |
