# 论文阅读与复现计划

## 目标

导师当前任务已经明确为基于示波器观测和电控偏振控制器的自动锁模。本文件中的 2024 年论文《Optimizing ultrashort pulse in fiber laser based on artificial intelligence algorithm》仍可作为物理仿真和优化方法参考，但不再作为近期主线复现目标。近期论文阅读优先服务于锁模状态表征、PC 参数搜索和实验闭环。

复现不是逐行复制，而是重建一个可解释、可验证的研究闭环。

## 启动条件

本计划不作为当前基础阶段的立即任务。正式生成论文数据和训练模型前，必须满足：

1. 自动锁模的示波器判态、PC 通信和基础搜索闭环已经形成可运行基线；
2. 已知目标腔的基本结构、元件顺序和参数来源；
3. 已完成高斯脉冲、FFT、FWHM 和时间带宽积验证；
4. 已完成纯色散、纯 SPM 和 NLSE/SSFM 的模块验证；
5. 时间窗、采样点、步长、单位和傅里叶变换约定已经固定；
6. 已定义单脉冲、多脉冲、连续波、失锁和数值失败的判定方式；
7. 简单基线模型与完整物理模型的复核流程已经设计。

在满足这些条件前，可以阅读论文摘要、系统图和结论，用于理解导师给出资料的目的，但不把“读懂网络结构”当作已经具备复现条件。

## 1. 系统边界

### 输入参数候选

- 增益带宽；
- 增益饱和能量；
- 增益光纤非线性系数；
- 无源光纤非线性系数；
- 可饱和吸收体调制深度；
- 可饱和吸收体饱和功率；
- 小信号增益。

第一版可以减少到 3～4 个最重要参数，确保流程正确后再扩展到 7 个参数。

### 输出指标候选

- 脉冲 FWHM；
- 脉冲能量；
- 峰值功率；
- 光谱宽度和 TBP；
- 单脉冲/多脉冲/未锁模分类；
- 往返收敛速度和稳定性指标。

仅优化脉宽、能量和峰值功率可能把结果推向不稳定或多脉冲区域，因此建议至少加入状态分类或稳定性约束。

## 2. 第一步：建立参数数据字典

每个参数必须记录：

| 字段 | 含义 |
| --- | --- |
| 名称和符号 | 例如 `β₂`、`γ`、`E_sat` |
| 物理意义 | 它影响哪一个过程 |
| SI 单位 | 仿真内部统一单位 |
| 文献单位 | 便于和论文对照 |
| 取值范围 | 下限、上限和依据 |
| 变换方式 | 线性采样或对数采样 |
| 来源 | 教材、论文、器件参数或导师提供 |

目标论文参数表中存在需核对的单位和上下限疑点。没有完成数据字典前，不开始批量生成数据。

## 3. 第二步：逐模块验证物理仿真

建议测试顺序：

1. 高斯脉冲 FFT 和逆 FFT；
2. 纯色散传播，与解析展宽趋势比较；
3. 纯 SPM，检查能量守恒和光谱展宽；
4. NLSE 的 SSFM 步长收敛；
5. 无源光纤；
6. 增益光纤；
7. 可饱和吸收体；
8. 输出耦合器；
9. 完整腔内往返。

每个模块需要至少一个正常测试和一个边界测试。不要把未经验证的所有组件一次性拼起来调参。

## 4. 第三步：定义状态和收敛标准

可以从下列标准开始，再根据实际系统修改：

- 连续若干次往返的能量相对变化小于阈值；
- 脉宽和峰值功率变化小于阈值；
- 相邻往返复包络在允许的时间平移和相位差后足够接近；
- 时域中只有一个主要脉冲；
- 波形未接触时间窗边界；
- 光谱未接触频率窗边界。

需要保存失败原因，而不是只丢弃失败样本。失败区域本身对逆向设计和实验控制非常重要。

## 5. 第四步：生成数据集

### 采样策略

- 调试阶段：规则网格或少量随机样本；
- 正式阶段：Latin hypercube、Sobol 或其他空间填充采样；
- 对跨数量级参数使用对数采样；
- 在预期相变或失锁边界增加采样密度。

### 每个样本应保存

- 原始参数；
- 最终指标；
- 状态标签；
- 收敛所需往返次数；
- 随机种子；
- 仿真版本和配置哈希；
- 是否发生数值异常。

## 6. 第五步：训练代理模型

### 基线

先使用简单模型确认数据是否可学习：

- 均值预测；
- 线性或多项式回归；
- 简单树模型；
- 小型 MLP。

### 数据划分

- 常规训练/验证/测试集；
- 单独保留靠近参数边界的测试集；
- 若同一参数点具有多个随机种子，不要把高度相关样本分到训练和测试两侧；
- 最好增加超出常规训练分布但仍物理允许的压力测试。

### 评价指标

- MAE、RMSE、相对误差；
- 每个输出的最坏误差；
- 边界区域误差；
- 状态分类的混淆矩阵；
- 推理速度相对 SSFM 的提升。

高 `R²` 或高相关系数不能替代误差分布和物理有效性检查。

## 7. 第六步：优化与物理复核

### 单目标示例

- 最短稳定脉宽；
- 最大稳定脉冲能量；
- 最大稳定峰值功率。

### 多目标示例

- 脉宽最小、能量最大，同时限制多脉冲概率；
- 提高峰值功率，同时限制 TBP 和往返波动；
- 在性能与参数敏感性之间折中。

### 必须执行的复核

1. 优化器在代理模型上产生候选点；
2. 检查候选点是否位于允许参数范围；
3. 使用完整 SSFM 重新计算；
4. 使用不同噪声种子重复仿真；
5. 在候选点附近扰动参数，检查鲁棒性；
6. 只有通过上述检查的候选点才可以称为有效优化结果。

## 8. 光纤/AI方向确认后的第一版研究题目

> 基于物理仿真代理模型的锁模光纤激光器多目标逆向设计

### 最小创新点候选

- 把单脉冲、多脉冲和失锁状态纳入建模，而不是只保留单脉冲数据；
- 使用物理约束或不确定度估计避免优化器利用代理模型误差；
- 主动学习：只在代理模型最不确定或最可能改进的区域运行昂贵 SSFM；
- 对最优参数做敏感性与鲁棒性分析；
- 使用少量实验数据进行迁移或校正。

## 9. 中长期拓展方向

### 自动锁模控制

把示波器、光谱仪或 RF 频谱作为观测，把电控偏振器、泵浦功率等作为执行器，形成：

```text
状态观测 → 特征/模型估计 → 参数搜索或控制策略 → 执行器 → 状态诊断与恢复
```

这与 RoboMaster 中的“观测—状态估计—预测—控制—诊断”链路高度相似，但必须先确认实验平台能够安全、稳定地提供可编程控制接口。

### 动力学快速预测

在可靠 SSFM 数据集基础上，可以进一步尝试 LSTM、神经算子或 PINN。但评价标准必须包括长期滚动误差、不同腔参数下的泛化和对新动力学状态的识别能力。
