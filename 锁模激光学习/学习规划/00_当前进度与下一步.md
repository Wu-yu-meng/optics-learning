# 当前进度与下一步

更新时间：2026-09-27

## 当前定位

导师项目的最终目标是：读取示波器数据，判断激光状态，并调整四通道电控偏振控制器，使光纤激光器进入或恢复锁模。

目前还不急着实现真实闭环。当前阶段的目标是：**围绕这个项目学习必需的光学知识，并用小型仿真验证理解；积累到能够看懂光路、参考代码和示波器数据后，再规划项目落地。**

学习不是从头通读所有光学内容，也不是在一个仿真中不断增加细节。每次只解决一个物理问题：

```text
学习一个项目相关概念
→ 用一个最小仿真观察现象
→ 能用自己的话解释结果
→ 停止扩展，进入下一个概念
```

- DFT 频率轴由采样点数和采样间隔决定：`T = NΔt`、`Δf = 1/T`、`f_k = k/(NΔt)`；
- 对实电场 `E(t)` 做 FFT 与对复包络 `A(t)` 做 FFT 的结果含义不同；
- 示波器不能直接观察数百 THz 的光载波，也不能直接测出飞秒脉宽。

已经完成的仿真：

- 使用 C++ 叠加多个等间隔频率；
- 比较全部同相、线性相位、固定随机相位和变化随机相位；
- 使用 OpenCV 显示空间中的电场与相对光强；
- 使用 Foxglove 显示 `x = 0` 处信号随时间的变化。
- 已增加二次频谱相位和非等间隔频率且初相位为零的情况，目前共六种多光波叠加情况。
- 已实现第七种高斯脉冲，包含复包络、载波电场和空间可视化。
- 已在 `PulseFFT/fft.cpp` 中固定 `x = 0`，对高斯脉冲实电场进行均匀时间采样并使用 `cv::dft` 完成 FFT。
- 当前 FFT 参数为 `N = 1000`、`Δt = 0.5 fs`：时间窗口 `T = 500 fs`，采样频率 `2000 THz`，奈奎斯特频率 `1000 THz`，频率间隔 `Δf = 2 THz`。
- 已绘制正频率范围 `0～1000 THz` 的归一化频谱强度 `|F(f)|²`，加入横纵坐标、单位、网格和峰值频率标注；当前峰值约为载波频率 `500 THz`。
- 当前图中的 `I` 为瞬时电场平方；它与包络强度 `|A(t)|²`、探测器实际输出并不相同，这一区别已经记录，留到“实验观测”阶段继续学习。
- 当前 FFT 的输入是含载波的实电场 `E(t)`，不是复包络 `A(t)`；因此当前频谱使用绝对光频率，并在 `500 THz` 附近出现峰值。包络 FFT 则应以相对载波的频率偏移为横轴并以 `0` 为中心。
- 已理解当前频谱峰值位于 `500 THz`，是因为高斯脉冲的光谱以载波频率为中心；当前几乎没有明显旁瓣，是因为使用了平滑的高斯包络，并且载波频率恰好落在 DFT 频点上。

目前的多纵模叠加与 FFT 仿真已经回答了：

> 多个等间隔纵模如何形成周期性波形，相位关系为什么决定脉冲是否集中；有限时间采样如何通过 FFT 得到频谱，以及当前高斯脉冲的频谱为什么位于载波频率附近。

因此这一轮仿真已经完成任务。`sech²`、自动 FWHM、时间带宽积和不同脉宽的定量比较保留为以后按需补充的支线，不作为进入项目光路学习的前置条件。暂时不继续加入精确探测器、真实示波器带宽、三维传播或完整激光腔。

## 项目需要学习的知识主线

只保留五块知识：

1. **激光器与项目光路**：环形腔、各器件作用、脉冲的一次往返；
2. **超短脉冲的数值表示**：包络、高斯/`sech²`、FFT、脉宽和光谱；
3. **光纤中的脉冲传播**：色散、非线性和二者竞争；
4. **偏振与锁模机制**：偏振、双折射、PC、Kerr 效应和 NPR/NPE；
5. **实验观测与自动控制**：探测器、示波器、锁模状态判断和 PC 搜索。

这五块已经覆盖项目所需的主要知识。CEP、阿秒物理、完整量子理论、固体激光器和其他锁模方法目前都不是主线。

### 停止条件

当你能够回答下面五个问题，就结束这一小步：

1. `LD` 产生的是什么光，它为什么叫泵浦光而不是项目最终需要的信号光？
2. `WDM` 为什么能让不同波长的光走到同一根光纤中？它会不会把 980 nm 直接“变成”1550 nm？
3. 泵浦能量真正转移给信号光的器件为什么是 `EDF`，而不是 `WDM`？
4. 为什么 980 nm 泵浦能够带来约 1550 nm 的激光输出，而不是一个 980 nm 光子简单变成一个 1550 nm 光子？
5. 能否在项目图中区分泵浦路径、腔内信号循环路径和 OC 后的输出路径？

## 后续顺序

按下面顺序推进：

```text
LD、WDM、EDF：泵浦能量如何变成信号增益（当前）
→ 环形腔、OC、ISO、SMF：循环、单向传播、输出与损耗
→ 偏振、两个正交分量、双折射与 PC
→ 核实实际锁模机制；若为 NPR/NPE，再学习 Kerr 效应和强度相关损耗
→ OC 后的放大、探测器与示波器信号
→ 锁模状态判定、PC 通信和自动搜索
```

完成 `LD → WDM → EDF` 后，再阅读《飞秒激光技术》PDF 第 190 页图 6.3.3，对照项目内环光路，为 `OC`、`ISO`、`SMF` 标注“输入、输出、作用和拿掉后的后果”，并尝试讲清光在腔内一次往返经历了什么。

随后学习偏振，最小仿真是用两个正交电场分量，改变幅度比和相位差，画出电场端点的直线、椭圆和圆形轨迹。理解后再引入 Jones 向量和矩阵。阶段目标是能解释调 PC 改变了什么、为什么可能改变锁模条件。

不能由“有 PC”直接推断锁模机制，也不能认为所有激光器都靠调 PC 锁模。若实际采用 NPR/NPE，此时补充 Kerr 非线性物理图像，不必先完成传播计算。

按需支线：定量描述脉冲时再补 `sech²`、FWHM、时间带宽积和不同脉宽的 FFT 比较；需要理解传播时，再依次做纯色散、纯 SPM、最小 SSFM；理解器件后再对照 `CGLE.m` 识别模块。完整腔仿真仅在导师需求和参数条件支持时开展，不是自动锁模项目的必经门槛。

## 防止再次钻牛角尖的规则

- 一个仿真只回答一个主要问题；
- 达到停止条件后就进入下一项，不继续追求界面和动画效果；
- 先使用无量纲或相对单位，只有与实验数据比较时才追求真实参数；
- 没有学习到对应物理机制前，不提前搭建完整腔；
- 完整 CGLE 不是当前目标，只在各模块分别理解后再看；
- AI 和自动搜索在具备示波器判态知识以后再开始。
