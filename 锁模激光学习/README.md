# 锁模激光学习工作区

这个文件夹用于把激光基础、超快光学、锁模机制、实验测量、数值仿真和人工智能方法组织成一条可以执行、检查和汇报的学习路线。

导师任务已经明确为光纤激光器自动锁模：读取示波器数据，判断激光状态，并自动调整四通道电控偏振控制器，使系统进入或恢复锁模。因此，本工作区现在采用项目优先路线，不再保留光纤/固体二选一作为主线。

## 总体目标

完成共同路线后，应当能够：

1. 用自己的话解释激光产生、超短脉冲、色散、非线性和锁模的基本原理；
2. 看懂目标激光器的腔结构、元件作用和主要参数；
3. 理解光谱、示波器、RF 频谱、自相关和 FROG/SPIDER 分别提供什么证据；
4. 使用 C++ 验证时频关系、色散传播、基本非线性和偏振演化；
5. 理解电控 PC 为什么会改变 NPR/NPE 锁模条件；
6. 从示波器波形提取可解释特征并建立锁模质量评分；
7. 完成 PC 控制、示波器采集、参数搜索和安全停止组成的实验闭环；
8. 能向导师清楚汇报已掌握内容、当前证据、存在问题和下一步计划。

## 学习原则

- **物理先于 AI**：先知道输入、输出和约束的物理意义，再训练模型。
- **阶段关卡代替赶进度**：读完章节不等于掌握，完成解释、计算或实验输出后再进入下一阶段。
- **项目相关内容优先**：重点学习光纤环形腔、偏振、双折射、NPR、实验判态和闭环控制；暂缓与项目无关的固体激光器内容。
- **教材按问题查阅**：优先阅读与当前问题直接相关的章节，不要求从头到尾通读。
- **关键概念用代码验证**：至少画出一张图，观察参数改变后的趋势。
- **公式检查四件事**：变量含义、单位、成立条件和极限情况。
- **先完成小闭环，再增加复杂度**：先做 FFT 和单段传播，再做完整腔；先做物理基线，再考虑 AI。
- **代理模型不能代替物理验证**：优化结果必须回到完整模型，最终还要接受实验验证。
