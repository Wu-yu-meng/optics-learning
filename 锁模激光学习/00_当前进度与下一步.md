# 当前进度与下一步

更新时间：2026-09-14

## 当前定位

导师项目的最终目标是：读取示波器数据，判断激光状态，并调整四通道电控偏振控制器，使光纤激光器进入或恢复锁模。

目前还不急着实现真实闭环。当前阶段的目标是：**围绕这个项目学习必需的光学知识，并用小型仿真验证理解；积累到能够看懂光路、参考代码和示波器数据后，再规划项目落地。**

学习不是从头通读所有光学内容，也不是在一个仿真中不断增加细节。每次只解决一个物理问题：

```text
学习一个项目相关概念
→ 用一个最小仿真观察现象
→ 能用自己的话解释结果
→ 停止扩展，进入下一个概念
```

## 已经完成

教材阅读：

- 《超快激光原理与技术》1.1.1～1.1.3；
- 《超快激光原理与技术》2.1、2.3。

已经建立的概念：

- 泵浦、粒子数反转、受激辐射、谐振腔和激光模式；
- 纵模、模式间隔、多频率叠加与锁模；
- 载波、包络、电场和光强的基本区别；
- 频谱振幅与频谱相位共同决定时域脉冲；
- 示波器不能直接观察数百 THz 的光载波，也不能直接测出飞秒脉宽。

已经完成的仿真：

- 使用 C++ 叠加多个等间隔频率；
- 比较全部同相、线性相位、固定随机相位和变化随机相位；
- 使用 OpenCV 显示空间中的电场与相对光强；
- 使用 Foxglove 显示 `x = 0` 处信号随时间的变化。

这个仿真已经回答了：

> 多个等间隔纵模如何形成周期性波形，相位关系为什么决定脉冲是否集中。

因此它现在已经完成任务。暂时不继续加入精确探测器、真实示波器带宽、三维传播或完整激光腔。

## 项目需要学习的知识主线

只保留五块知识：

1. **激光器与项目光路**：环形腔、各器件作用、脉冲的一次往返；
2. **超短脉冲的数值表示**：包络、高斯/`sech²`、FFT、脉宽和光谱；
3. **光纤中的脉冲传播**：色散、非线性和二者竞争；
4. **偏振与锁模机制**：偏振、双折射、PC、Kerr 效应和 NPR/NPE；
5. **实验观测与自动控制**：探测器、示波器、锁模状态判断和 PC 搜索。

这五块已经覆盖项目所需的主要知识。CEP、阿秒物理、完整量子理论、固体激光器和其他锁模方法目前都不是主线。

## 现在的下一步

### 当前学习问题

**超短脉冲在代码中应当怎样表示，为什么后续光纤传播仿真使用包络 `A(t)`，而不再逐个模拟数百 THz 的载波？**

### 当前阅读

- 回看《超快激光原理与技术》2.3 中脉冲形状、时域和频域的相关内容；（完成）
- 不重新深挖载波包络相位；
- 遇到 FFT 采样问题时，再查时间窗口、采样间隔和频率轴。

### 当前最小仿真

在现有 `PulseFFT` 之后，新建一个独立的小程序，完成：

1. 直接生成一个高斯脉冲包络 `A(t)`；
2. 绘制包络强度 `|A(t)|²`；
3. 对 `A(t)` 做 FFT，绘制光谱强度；
4. 改变脉冲宽度，观察“时间越窄，频谱越宽”。

这一轮先不加入：

- `sech²` 脉冲；
- 自动 FWHM；
- 时间带宽积；
- 二次频谱相位；
- 光纤传播；
- 探测器模型。

### 停止条件

当你能够回答下面三个问题，就结束这个小仿真：

1. `A(t)` 表示什么，为什么不需要在其中逐周期画出光载波？
2. 为什么计算光学频谱时要对电场包络做 FFT，不能把“光强随时间的 FFT”直接当作光学频谱？
3. 为什么脉冲变窄时，光谱会变宽？

## 后续顺序

完成当前小仿真后，按下面顺序推进：

```text
高斯包络与 FFT
→ 补充 sech²、FWHM 和时间带宽积
→ 只模拟色散造成的脉冲展宽
→ 只模拟自相位调制造成的频谱展宽
→ 用最小 SSFM 同时模拟色散与非线性
→ 学习偏振、双折射、PC 和 NPR
→ 模拟 NPR 等效透过率
→ 看懂参考 CGLE 中每个模块
→ 再规划示波器判态、PC 通信与自动搜索
```

同时穿插阅读实际光路：每学到一个器件或作用，就回到光路图中找它的位置，不要求现在一次看懂整套系统。

## 防止再次钻牛角尖的规则

- 一个仿真只回答一个主要问题；
- 达到停止条件后就进入下一项，不继续追求界面和动画效果；
- 先使用无量纲或相对单位，只有与实验数据比较时才追求真实参数；
- 没有学习到对应物理机制前，不提前搭建完整腔；
- 完整 CGLE 不是当前目标，只在各模块分别理解后再看；
- AI 和自动搜索在具备示波器判态知识以后再开始。
